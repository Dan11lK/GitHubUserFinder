# GitHub User Finder

Автор: Даниил Кургузов

## Описание

GitHub User Finder, это GUI приложение на Python для поиска пользователей GitHub.
Приложение использует GitHub API, показывает список найденных пользователей и позволяет сохранять пользователей в избранное.
Избранные пользователи сохраняются в файл favorites.json.

## Использованные технологии

Python
Tkinter
Requests
GitHub REST API
JSON
Git

## Как использовать API

Приложение отправляет GET запрос к GitHub API:

https://api.github.com/search/users

В запрос передается параметр q, это текст из поля поиска.
Также передается параметр per\_page, чтобы ограничить количество результатов.

Пример запроса:

https://api.github.com/search/users?q=octocat\&per\_page=20

GitHub API возвращает JSON данные.
Из ответа берется список items.
В каждом элементе есть login, html\_url, avatar\_url и type.

## Установка

1. Установите Python.
2. Откройте папку проекта в терминале.
3. Установите зависимости:

python -m pip install -r requirements.txt

4. Запустите приложение:

python main.py

## Как пользоваться

1. Введите имя или логин пользователя GitHub.
2. Нажмите кнопку Найти.
3. Выберите пользователя из списка.
4. Нажмите Добавить в избранное.
5. Пользователь сохранится в favorites.json.
6. Для открытия профиля нажмите Открыть профиль.
7. Для удаления из избранного выберите пользователя и нажмите Удалить.

## Проверка ввода

Если поле поиска пустое, приложение покажет сообщение об ошибке.

## Примеры тестов

Пустой ввод, приложение показывает ошибку.
Ввод octocat, приложение показывает пользователей GitHub.
Добавление пользователя в избранное, пользователь появляется в правом списке.
Повторное добавление одного пользователя, приложение показывает сообщение.
Удаление пользователя из избранного, пользователь удаляется из списка и файла favorites.json.
